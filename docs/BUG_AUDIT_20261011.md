# Проверка похожих ошибок — 11 октября 2026

Ориентир: существующие `time.spec.ts`, `preview.spec.ts`, `motion.spec.ts` и отчёт PROJECT_AUDIT. Предыдущие сообщения пользователя в этой сессии недоступны; классы ошибок восстановлены по коду и проверкам проекта. Уже существовавшие изменения в рабочей папке сохранены.

## Исправления

- Прогноз и совместный план больше не показывают ответ или ошибку запроса, если после его начала изменились параметры, даже если значения впоследствии вернулись к прежним. Общий `useCalculation` защищает от повторного запуска и отменяет запрос при размонтировании.
- Расчёт заказа/поставки сбрасывается при изменении ревизии склада и часового пояса. Запоздавшие ответы после редактирования полей игнорируются. Ошибки сохранения сбрасываются также при исправлении названия, ID, категории и настроек.
- После изменения количеств закупки черновик поставки требует повторной проверки. Изменение склада также блокирует создание черновика по устаревшему расчёту.
- Аналитика сохраняет применённый период при обновлении snapshot/SSE и повторно загружает этот период. Предыдущий запрос отменяется при замене периода или размонтировании. Конец выбранного дня включает дробные секунды; обратный диапазон дат проверяется до запроса.
- ID продуктов и блюд кодируются в URL архивирования: `#`, `?` и другие специальные символы не меняют адрес запроса.
- Dockerfile копирует генератор темы перед frontend-сборкой. README и прежний аудит уточнены. Полная Docker-сборка не проверена: Docker CLI отсутствует.
