## Использование

Администратор открывает «Журнал событий» в левом меню. Поиск — название продукта, номер поставки, ID или код события; категории сужают список. «Аккаунты» → «Изменить аккаунт» менеджера → «Страницы в меню менеджера» → «Сохранить аккаунт». Нужно оставить хотя бы одну страницу. Как и остальные изменения аккаунта, сохранение завершает прежние сессии/ключи. Видимость страниц не меняет API-права роли.

Архив eventLog сохраняется отдельно от очищаемого потока events. При обновлении приложения переносится сохранившаяся история events; уже удалённые до обновления записи восстановить невозможно. Рабочий API необходимо перезапустить для применения backend-изменений.
